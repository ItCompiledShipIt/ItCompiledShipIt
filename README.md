## Zenith

[Zenith](https://github.com/ItCompiledShipIt/zenith) is one Paper plugin that replaces EssentialsX, CMI, LuckPerms, and the everyday admin/QoL stack — essentials, economy, claims, quests, NPCs, shops, moderation, permissions, and more, plus an embedded web dashboard. v0.127.0, Paper 26.3, Java 25. It runs my server.

## D00M

[D00M](https://github.com/ItCompiledShipIt/D00M) is a Doom-style FPS written from scratch in Rust — v1.0.0. Textured software raycaster, procedural textures, sprites and weapons, enemy AI, sliding doors, explosive barrels, automap. No engine, no asset files.
